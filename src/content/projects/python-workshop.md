I learnt Python by making things I could play or use. These programs grew independently, from small games to a text editor, a phonebook and experiments with ciphers.

## Inside the collection

Space War uses a keyboard-controlled ship and an arena of enemies and allies. Textpad works with plain-text files, while Hackboard is a guessing game about the numbers that make up a colour. Each program runs on its own.
